# Google Cloud's gen AI offerings

**Domain:** gcgenai-02 — Task 2.1, 2.2, 2.3, 2.4, 2.5
**Verified:** 2026-11-03
**Concepts:** ai-first, hypercomputer, tpu, model garden, agent platform, agent studio, google ai studio, gemini app, gemini enterprise, gemini for google workspace, customer engagement suite, conversational agents, agent assist

> the current exam guide before sealing.

## Why this is on the exam

~35% of the exam — the **largest** section. It is mostly product recognition: given a
business need, name the Google Cloud offering that meets it.

## Scope — official objectives

| Task | Objective (verbatim from the exam guide) |
|---|---|
| 2.1 | Describe Google Cloud's strengths in the field of gen AI |
| 2.2 | Describe how Google Cloud's prebuilt gen AI offerings enable AI powered work |
| 2.3 | Describe how Google Cloud's gen AI offerings improve the customer experience |
| 2.4 | Describe how Google Cloud empowers developers to build with AI |
| 2.5 | Define the purpose and types of tooling for gen AI agents |

## Which offering for which audience

| The need | The offering |
|---|---|
| Individual knowledge work, chat and Gems | **Gemini app / Gemini Advanced** |
| AI across an enterprise's own content, with multimodal search and custom agents | **Gemini Enterprise** |
| AI inside Docs, Sheets, Gmail, Meet | **Gemini for Google Workspace** |
| Customer-facing conversational support | **Customer Engagement Suite** — Conversational Agents, Agent Assist, Conversational Insights, CCaaS |
| Developers building and deploying custom agents and models | **Agent Platform** (Model Garden, Agent Search, AutoML) |
| Answers grounded in enterprise or web content | Google Cloud's **RAG offerings** — prebuilt RAG with Agent Search, RAG APIs, grounding with Google Search |

## Google Cloud's stated strengths (2.1)

The guide enumerates them, and the exam quotes them back: an **AI-first approach**; an
**enterprise-ready platform** (responsible, secure, private, reliable, scalable); a
**comprehensive ecosystem** integrating gen AI across Google products; an **open
approach**; **AI-optimized infrastructure** (hypercomputer, custom-designed TPUs, GPUs,
data centres); **control over your data**; and **democratized development** through
low-code and no-code tools, pre-trained models and APIs.

## Agent tooling (2.5)

Agents reach the outside world through **extensions, functions, data stores and
plugins**. Pre-built APIs the guide names for agent tooling include Speech-to-Text,
Text-to-Speech, Translation, Document AI, Cloud Vision, Video Intelligence and Natural
Language, alongside Cloud Storage, databases, Cloud Functions and Cloud Run.

## Traps

- **Trap:** offering a developer platform where the scenario describes a non-technical
  business user, or vice versa. Audience is the usual discriminator.
- **Trap:** confusing **Agent Studio** with **Google AI Studio** — objective 2.5 asks
  you to decide *when to use which*.
- **Trap:** answering a customer-experience question (2.3) with a general developer
  product (2.4).
- **Trap:** stale product names. These surfaces have been renamed more than once;
  trust the current exam guide over memory.
